# Rollback demonstration

## Описание

В данной части реализована демонстрация механизма отката (rollback) приложения к предыдущей рабочей версии.

Для демонстрации используются два Docker-образа:
- `lab03-rollback-broken` — неисправная версия приложения, процесс которой завершается с ошибкой;
- `lab03-rollback-good` — рабочая версия приложения, предоставляющая endpoint `/health`.

## Структура

- `rollback-demo/Dockerfile` — Dockerfile неисправной версии;
- `rollback.ps1` — PowerShell-скрипт восстановления рабочей версии;
- `report/` — материалы отчёта и скриншоты.

## Выполнение

1. Собрать неисправный Docker-образ.
2. Запустить контейнер неисправной версии.
3. Проверить его состояние и убедиться, что endpoint `/health` недоступен.
4. Удалить неисправный контейнер.
5. Запустить скрипт `rollback.ps1`.
6. Дождаться успешного ответа от endpoint `/health`.

Для запуска отката из корня проекта используется команда:

```powershell
.\lab03\lab03-star\rollback.ps1
```

## Результат

Откат к рабочей версии выполнен успешно. Endpoint `/health` вернул JSON-ответ:

```json
{"status":"ok"}
```

Время восстановления при последнем запуске скрипта составило 1,80 секунды.

Демонстрация выполнена локально с использованием Docker. Откат запускается вручную с помощью PowerShell-скрипта.
