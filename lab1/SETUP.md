# Инструкция по запуску лабораторной работы №0

## 1. Клонирование проекта

Склонировать репозиторий:

```bash
git clone https://github.com/marias-eng/skip.git
```

Перейти в папку лабораторной работы №0:

```bash
cd skip/lab0
```

## 2. Установка зависимостей Backend

Создать виртуальное окружение:

```bash
python -m venv .venv
```

Активировать виртуальное окружение в Windows:

```powershell
.venv\Scripts\activate
```

Установить необходимые библиотеки:

```powershell
pip install -r requirements.txt
```

## 3. Настройка базы данных PostgreSQL

Необходимо установить PostgreSQL.

Создать базу данных с названием:

```text
lab0
```

Для восстановления базы данных используется файл:

```text
database/dump.sql
```

Команда восстановления:

```powershell
psql -U postgres -d lab0 -f database/dump.sql
```

Если команда `psql` не распознаётся, необходимо указать полный путь к файлу `psql.exe`.

Файл `database/init.sql` содержит SQL-команды для создания таблицы `tasks`.

## 4. Настройка подключения к базе данных

В папке `lab0` необходимо создать файл:

```text
.env
```

Его можно создать на основе файла:

```text
.env.example
```

В файле `.env` необходимо указать:

```text
DB_HOST=localhost
DB_PORT=5432
DB_NAME=lab0
DB_USER=postgres
DB_PASSWORD=ваш_пароль
```

Вместо `ваш_пароль` необходимо указать пароль пользователя PostgreSQL.

Файл `.env` не должен загружаться в GitHub, так как содержит пароль от базы данных.

## 5. Запуск Backend

Из папки `lab0` выполнить:

```powershell
python backend/app.py
```

После запуска Backend будет доступен по адресу:

```text
http://127.0.0.1:5000
```

## 6. Запуск Frontend

Открыть второй терминал.

Перейти в папку `lab0`:

```powershell
cd skip/lab0
```

Запустить локальный HTTP-сервер:

```powershell
py -m http.server 5500 --directory frontend
```

После запуска открыть в браузере:

```text
http://127.0.0.1:5500/index.html
```

## 7. Работа приложения

Для получения списка задач используется:

```text
GET /tasks
```

Для добавления новой задачи используется:

```text
POST /tasks
```

Пример данных:

```json
{
    "title": "Купить молоко"
}
```

После добавления задача сохраняется в PostgreSQL и отображается на странице.

Дата и время создания задачи записываются автоматически и отображаются на странице в формате:

```text
1 октября 2026, 16:42
```
